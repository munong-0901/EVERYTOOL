어떤 도구가 필요하세요?

원하는 기능을 선택해 바로 시작할 수 있어요.

13개 도구

복잡한 작업은 간단하게.

사진 수십 장의 크기를 한꺼번에 바꾸고, 여러 PDF를 합치는 작업을 브라우저에서 직접 처리하세요. 단순 계산뿐 아니라 반복되는 파일 작업 시간을 줄이는 데 집중합니다.

설치 불필요모바일 지원파일 다중 선택

이용 안내

이미지·PDF 작업은 브라우저에서 처리하며 선택한 파일은 서버로 업로드하지 않습니다. PDF 편집 엔진은 첫 이용 시 외부 CDN에서 다운로드하므로 인터넷이 필요합니다. 중요한 파일은 결과를 확인하고 원본을 별도 보관하세요.

자주 묻는 질문

서비스 이용 전 확인해 주세요.

도구를 사용하려면 회원가입이 필요한가요?

아니요. 현재 버전은 회원가입이나 로그인 없이 바로 이용할 수 있습니다.

모바일에서도 사용할 수 있나요?

네. 화면 크기에 맞춰 레이아웃이 변경되는 반응형 웹사이트입니다.

입력한 정보가 저장되나요?

현재 계산 및 텍스트 도구는 브라우저 안에서 처리하며 서버로 전송하지 않습니다. 중요한 정보는 직접 저장해 주세요.

새로운 도구가 추가되나요?

사용자에게 도움이 되는 기능을 검토해 지속적으로 추가할 수 있도록 설계했습니다.

상황별로 바로 쓰는 무료 도구

도구를 고르는 데 시간을 쓰지 않도록 자주 발생하는 작업을 기준으로 정리했습니다. 각 페이지에는 입력 방법과 계산 기준, 실제 예시를 함께 제공합니다.

이미지·문서 일괄 작업

이미지 편집기에서 사진을 한 번에 줄이고, PDF 편집기에서 보고서를 합치거나 페이지를 추출하세요.

과제·문서 작성

자소서 분량 확인은 글자 수 세기, 영문 제목 정리는 대소문자 변환을 사용하세요.

일정·계획 관리

두 날짜 사이의 기간은 날짜 차이 계산기로 확인하고, 출퇴근·휴게시간은 근무시간 계산기로 계산하세요.

개발·데이터 정리

JSON 포맷터로 형식을 검증하고 인코딩 도구로 텍스트 표현을 변환하세요.

영상·일상 작업

동영상 변환은 브라우저 지원 범위를 먼저 확인하고, 더치페이로 공동 비용을 나눠 보세요.
