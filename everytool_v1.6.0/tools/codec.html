인코딩·디코딩 변환기

Base64, URL, HTML, Unicode, Hex 변환을 한곳에서 처리하세요. 입력 내용은 서버로 전송하지 않고 브라우저 안에서 변환합니다.

Base64는 암호화가 아닙니다. 민감한 정보를 보호하는 용도로 사용하지 마세요.

형식별 사용 방법

Base64는 UTF-8 텍스트를 ASCII 문자로 표현합니다. 한글과 이모지도 지원합니다. URL은 웹 주소의 쿼리 값에 사용할 문자를 변환합니다. HTML은 특수문자를 엔티티로 바꿉니다. Unicode는 자바스크립트 스타일의 이스케이프 문자열로 바꾸며, Hex는 UTF-8 바이트를 16진수로 표시합니다.

Base64와 암호화는 어떻게 다른가요?

Base64는 데이터를 표현하는 인코딩 형식으로, 누구나 원래 내용으로 디코딩할 수 있습니다.

URL의 + 문자는 공백으로 변환되나요?

이 도구는 encodeURIComponent/decodeURIComponent 규칙을 사용합니다. +를 공백으로 처리하는 폼 인코딩과 다릅니다.

Hex 입력 형식은 무엇인가요?

디코딩할 때는 16진수 두 자리씩 입력하세요. 공백으로 구분해도 됩니다. 예: ED 95 9C

인코딩과 암호화의 차이

Base64

Base64는 데이터를 문자 형태로 표현하는 인코딩이지 암호화가 아닙니다. 누구나 다시 디코딩할 수 있습니다.

URL 인코딩

주소의 특수문자를 안전하게 표현하기 위한 방식으로, 비밀정보 보호 수단이 아닙니다.

HTML 이스케이프

<, >, & 같은 문자를 HTML에서 안전하게 표시하도록 바꾸는 작업입니다.
