PDF 통합 편집기

여러 PDF를 합치거나 특정 페이지만 추출·분할하고, 전체 또는 선택 페이지를 회전하세요. 변환 결과는 새 PDF 파일로 저장됩니다.

1. PDF 파일 선택

PDF를 끌어놓거나 눌러서 선택여러 파일을 추가할 수 있습니다. 잠금이 걸린 PDF는 지원하지 않습니다.

    2. 작업 선택

    1부터 시작. 빈칸은 전체 페이지(회전만)
    PDF를 선택하면 페이지 수를 확인할 수 있습니다.

    PDF 합치기·분할·추출 사용 가이드

    PDF 합치기

    여러 PDF를 올린 뒤 파일 목록의 ↑ ↓ 버튼으로 순서를 조정하세요. 합치기는 목록 순서대로 페이지를 이어 붙입니다. 예를 들어 표지 1장 + 보고서 8장 + 참고자료 3장을 결합하면 12페이지 PDF가 만들어집니다.

    필요한 페이지만 추출하기

    한 개의 PDF를 선택하고 페이지 번호에 2-4, 7을 입력하면 2·3·4·7페이지만 포함하는 새로운 PDF를 생성합니다. 페이지 번호가 실제 페이지 범위를 벗어나면 작업을 중단하고 안내합니다.

    페이지별 분할 및 회전

    분할은 선택한 PDF의 각 페이지를 별도 PDF로 만든 뒤 ZIP으로 다운로드합니다. 회전은 90°·180°·270° 중 선택한 각도로 저장하며, 선택한 페이지에만 적용할 수도 있습니다. 기존 페이지의 회전 상태를 기준으로 회전 각도를 더합니다.

    알아둘 점

    이 도구는 PDF 페이지를 재배열하는 용도이며 PDF 내부 텍스트 수정, OCR, PDF 용량 압축, 암호 해제는 지원하지 않습니다. 서명, 대화형 양식 등 일부 복잡한 PDF는 결과를 열어 확인하세요. PDF 처리 라이브러리를 처음 불러올 때 외부 CDN에 연결해야 하지만, 선택한 문서의 내용은 작업 과정에서 서버로 업로드하지 않습니다. 기기 성능과 메모리 상태에 따라 대형 PDF 처리에 실패할 수 있습니다.

    자주 묻는 질문

    원본 PDF는 변경되나요? 아니요. 새 파일을 생성합니다. 여러 문서를 합칠 수 있나요? 네. 순서를 바꾼 뒤 합칠 수 있습니다. 휴대폰에서도 되나요? 최신 브라우저에서 사용할 수 있지만 큰 문서는 PC가 더 안정적입니다.
