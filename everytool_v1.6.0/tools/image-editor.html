이미지 일괄 편집기

사진 여러 장을 한 번에 줄이고, 가로·세로 크기를 변경하고, JPG·PNG·WebP로 변환하세요. 결과는 개별 파일 또는 ZIP으로 다운로드할 수 있습니다.

1. 이미지 선택

이미지를 끌어놓거나 눌러서 선택JPG · PNG · WebP · GIF 첫 프레임(지원 시) / 여러 파일 선택 가능

    2. 변환 설정

    0은 원본 크기 유지
    0은 가로 비율에 맞춰 자동
    82% · PNG는 품질 설정 적용 안 됨
    이미지를 선택하면 시작할 수 있습니다.

    이미지 용량을 줄이면서 화질을 유지하는 방법

    이미지 파일이 큰 이유는 픽셀 수가 많거나 압축률이 낮기 때문입니다. 웹사이트·블로그에 쓰는 사진이라면 먼저 표시될 가로 크기에 맞춰 픽셀을 줄이고, JPEG 또는 WebP의 품질을 75~85% 정도부터 시험해 보세요. 최종 용량은 사진의 복잡도에 따라 달라집니다.

    실제 사용 예시

    가로 4000px인 여행 사진 25장을 올린 뒤 최대 가로 1200px, WebP, 품질 82%를 선택하면 비율을 유지하며 일괄 변환하고 ZIP으로 묶어 받을 수 있습니다. 파일 이름은 선택한 접두어 뒤에 001, 002처럼 번호를 붙입니다.

    JPG, PNG, WebP 중 무엇을 선택할까요?

    형식추천 용도
    JPG일반 사진, 높은 호환성 / 투명도 미지원
    PNG투명 배경, 글자가 포함된 그래픽 / 용량이 클 수 있음
    WebP웹 게시용 이미지 / 구형 프로그램에서는 지원 확인 필요

    주의사항 및 FAQ

    원본 파일은 바뀌나요? 아니요. 결과를 새 파일로 다운로드합니다. 움직이는 GIF도 변환되나요? 현재 기능은 GIF 애니메이션을 보존하지 않고 첫 프레임만 처리합니다. HEIC도 지원하나요? 브라우저별 지원이 달라 현재 공식 지원 형식에서 제외했습니다. 파일이 외부로 전송되나요? 변환은 브라우저의 Canvas API에서 이루어집니다. 대량의 초고해상도 이미지는 기기 메모리 때문에 실패할 수 있습니다.
