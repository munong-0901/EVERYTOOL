EVERYTOOL v1.6.0
GitHub 저장소에는 이 ZIP의 압축을 풀어 index.html과 tools, assets 폴더를 최상위에 업로드하세요.
신규: 이미지 일괄 편집기 (/tools/image-editor.html), PDF 통합 편집기 (/tools/pdf-editor.html).
이미지 ZIP 묶기용 JSZip은 assets/jszip.min.js에 포함되어 있습니다.
PDF 엔진 pdf-lib 1.17.1은 사용 시 jsDelivr 또는 unpkg에서 불러옵니다. 이때 네트워크가 막히면 PDF 기능이 작동하지 않습니다. 문서 자체는 업로드하지 않습니다.
동영상 변환기는 기존 제한 그대로이며, 이번 버전에서 새로 구현한 기능이 아닙니다.
실제 모바일 기기에서 파일 처리 테스트는 별도로 필요합니다.
