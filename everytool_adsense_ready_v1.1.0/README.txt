EVERYTOOL v1.1.0

변경: 12개 도구의 독립 URL과 설명/예시 페이지, 소개/개인정보/문의 페이지, 내부 링크, 빈 숫자 입력 검증, 광고 자리 표시 문구 제거.

배포: Cloudflare Pages Direct Upload에 ZIP 업로드.

필수 공개 전 작업:
1. 실제 운영자 문의 이메일을 contact.html에 입력.
2. privacy.html의 실제 처리 주체, 호스팅, 쿠키 및 광고 설정 검토.
3. 고유 도메인을 연결한 후 도메인 주소가 들어간 절대 canonical 및 sitemap.xml 생성.
4. PC/모바일에서 모든 도구 기능 테스트.
5. AdSense 정책 및 사이트 심사 기준을 확인하고 신청. 승인 보장 불가.
6. 광고 코드는 승인 및 필요한 동의 설정 후 추가.

참고: 원본 기능의 일반적인 구조를 유지했으며 외부 서비스 가입/배포는 수행하지 않았습니다.
