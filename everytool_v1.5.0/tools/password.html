비밀번호 생성기

브라우저의 보안 난수 기능을 사용해 임의 비밀번호를 생성합니다.

직접 계산하기

계산 방법 및 사용법

길이가 길고 서비스마다 다른 비밀번호를 사용하는 것이 좋습니다.

사용할 때 주의할 점

생성한 비밀번호는 안전한 비밀번호 관리자에 저장하고 다른 사람에게 공유하지 마세요.

자주 묻는 질문

결과를 그대로 사용해도 되나요?

입력한 값을 바탕으로 계산한 참고 결과입니다. 금융·세무·법률 등 중요한 판단은 공식 자료와 해당 기관의 안내를 함께 확인하세요.

입력 내용이 저장되나요?

이 도구의 계산은 브라우저에서 수행되며 입력 내용을 별도 서비스 서버로 보내는 기능은 구현되어 있지 않습니다. 다만 웹 호스팅 서비스의 접속 기록 등은 별도로 처리될 수 있습니다.

안전한 비밀번호를 만드는 방법

길이 우선

가능하면 충분히 긴 비밀번호를 사용하고 사이트마다 서로 다른 값을 사용하세요.

저장 방법

생성한 비밀번호는 신뢰할 수 있는 비밀번호 관리자에 보관하고, 메신저나 공개 문서에 적지 마세요.

2단계 인증

비밀번호만으로 계정을 보호하기보다 지원되는 서비스에서는 다중 인증을 활성화하세요.
